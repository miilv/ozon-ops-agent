# Плейбук: отзывы и вопросы

1. Новые отзывы: `ReviewAPI` (беты), вопросы: `Questions&Answers`.
2. 4-5★ — ответить сразу (T1): поблагодарить, по делу, без канцелярита и эмодзи-спама. 2-3 предложения.
3. 1-3★ — составить черновик ответа + разбор причины (брак? логистика? ожидания?) → в TG на апрув (T3). Если паттерн (3+ похожих) — инцидент в docs/incidents/.
4. Вопросы покупателей — отвечать фактами из карточки/знаний о товаре; не выдумывать характеристики (T1).
5. Журнал: сколько отвечено, темы, паттерны.

Тон: живой профессиональный русский, «мы», без «Уважаемый покупатель».
Верификация: ответ виден в API повторным чтением.
