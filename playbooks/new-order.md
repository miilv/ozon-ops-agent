# Плейбук: новый заказ (FBS, дропшиппинг)

Триггер: orders_watcher → алерт. Схема целиком: docs/PRODUCT.md.

1. Датчик шлёт в чат: состав, сумма, **дедлайн отгрузки** (ваш ППЗ принимает до 19:00; день-в-день = скидка Ozon).
2. Агент добавляет к алерту: экономику заказа (netback, маржа от последнего известного себеса) + напоминание-чеклист:
   - резерв у основного поставщика / fallback другие продавцы / Авито;
   - наличные на карте (банкоматы!), коробка НУЖНОГО семейства, скотч, стикеры, заряженный принтер;
   - видео сборки обязательно (без него нет компенсаций).
3. Оператор пишет в чат «купил X за Y» → зафиксировать закупку в ledger (себес этого заказа).
4. За 3 часа до дедлайна не отгружено → эскалация с тэгом оператора.
5. Отгружено → перенести факт в ledger, убрать из NOW.

Сборку в ЛК агент сам не прокликивает (Оператор делает в моб. приложении).
