# ozon-ops-agent

Каркас автономного операционного агента для магазина на Ozon: конституция, плейбуки,
Telegram-мост, датчики без LLM и детерминированные тулзы для денежных операций.
Работает на Claude Code (`claude -p`) по крону.

> *An ops-agent skeleton for an Ozon marketplace store: agent constitution, playbooks,
> Telegram bridge, LLM-free sensors and deterministic money-touching tools. Russian-language;
> built for [Claude Code](https://claude.com/claude-code).*

**Это шаблон, а не готовый продукт.** Он снят с работающей приватной системы: все
коммерческие данные, реквизиты и инфраструктурные адреса заменены плейсхолдерами
(`<STORE>`, `<SERVER_IP>`, `100000001`, …). Ищите их и подставляйте своё.

---

## Зачем это

Обычный дев-агент производит код: сессия одноразовая, артефакт — PR, истина — git.
Операционный агент производит **действия во внешнем мире** — цена изменена, отзыв
отвечен, из акции вышли — а мир живёт на серверах маркетплейса, не в вашем репо.
Из этой инверсии следует почти вся архитектура: явный слой «что происходит сейчас»
(`state/`), плейбуки вместо кодовой базы, верификация обратным чтением API вместо
тестов, уровни автономии вместо код-ревью.

Подробно — [AGENT-ARCHITECTURE.md](AGENT-ARCHITECTURE.md). Это самый содержательный
файл репозитория; если читать что-то одно, читайте его.

## Ключевые идеи

**Уровни автономии.** T0 — читать что угодно. T1 — обратимые действия сам. T2 — деньги,
но строго внутри `guardrails.yaml`. T3 — необратимое, только через апрув кнопкой в
Telegram, **таймаут = отказ**.

**Деньги считает код, не модель.** Netback и маржа — через тулзу по формуле из
`ozon-pnl-model.md`. Модель решает *что делать*, скрипт гарантирует *как посчитано*.

**Действие не выполнено, пока не подтверждено.** Поменяли цену → перечитали
`/v5/product/info/prices` → сошлось. Всё money-touching сначала с `--dry`.

**Датчик замечает, агент думает.** Дешёвые проверки — чистый Python по крону, без LLM.
Агент просыпается, только когда нужно суждение. Дешевле и не галлюцинирует.

**Журнал не зависит от дисциплины модели.** Три слоя: детерминированный `action_log` в
SQLite (пишется самой тулзой), stop-hook в конце сессии и ночной агент-секретарь,
который сверяет транскрипты сессий с журналом и дописывает пропущенное.

**Один бот-токен = один polling-процесс.** Из этого следует вся телеграм-архитектура:
токеном владеет только `tg-bridge`, все остальные ходят к нему по localhost HTTP.

## Быстрый старт

```bash
git clone --recurse-submodules https://github.com/<you>/ozon-ops-agent.git
cd ozon-ops-agent
cp .env.example .env        # заполнить ключи Ozon и токен бота
```

Дальше:
1. Пройдитесь по плейсхолдерам: `grep -rn '<STORE>\|<SERVER_IP>\|<ФИО>\|100000001' .`
2. Заполните `config/team.yaml` (реальные Telegram id) и `config/guardrails.yaml`.
3. Опишите магазин в `docs/PRODUCT.md` — агент читает его для контекста.
4. Поднимите `tg-bridge` как systemd-юнит, проверьте `curl 127.0.0.1:8765/history?limit=3`.
5. Повесьте кроны из [`docs/RUNBOOK.md`](docs/RUNBOOK.md).

Порядок сборки с нуля, по фазам — §11 в `AGENT-ARCHITECTURE.md`.

## Чего здесь нет

- **Состояния и истории.** `state/NOW.md`, журнал и постмортемы — пустые скелеты:
  в оригинале это живые операционные данные.
- **Ассортимента, поставщиков, себестоимости, цен.** `docs/PRODUCT.md` и
  `config/competitors.yaml` — заготовки.
- **`tools/pricing_engine.py`.** Конституция на него ссылается, здесь его нет:
  формула сильно зависит от вашей категории и схемы. Считайте `ozon-pnl-model.md`
  техзаданием на него.
- **Справочника Ozon.** Офлайн-копия базы знаний Ozon в оригинале лежит рядом
  (`ozon-baza-znaniy/`) — сюда не вошла, это контент Ozon, а не наш.
- **Секретов.** `.env` не в git ни здесь, ни в приватной версии.

## Предупреждения

- `tools/mpstats.py` — клиент внутреннего API плагина MPStats, полученный обратной
  разработкой расширения. `tools/ozon_scout.py` ходит в публичный `composer-api` Ozon,
  имитируя TLS-отпечаток браузера. Оба — на ваш риск и под вашу ответственность
  за соблюдение пользовательских соглашений сервисов.
- Ставки, тарифы и налоговые пороги в `ozon-pnl-model.md` и скилле
  `marketplaces-tax-ru` актуальны на середину 2026 года и **устаревают**. Сверяйтесь
  с первоисточником; налоговые расчёты показывайте бухгалтеру.
- Агент ходит в боевой ЛК и двигает реальные деньги. Начинайте с T0, `--dry` и узких
  guardrails.
