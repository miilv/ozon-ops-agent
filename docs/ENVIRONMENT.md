# ENVIRONMENT.md — переменные .env (без значений!)

`.env` живёт в корне репо ЛОКАЛЬНО и на СЕРВЕРЕ (`/home/ops/marketplaces/.env`), в git не
попадает никогда. Синк между машинами — только scp. Завёл новую переменную: опиши её здесь
и добавь руками в оба `.env`. Шаблон со всеми ключами — [`.env.example`](../.env.example).

| Переменная | Что |
|---|---|
| `OZON_CLIENT_ID`, `OZON_API_KEY` | Seller API магазина. Используют `tools/ozon.py`, датчики, скилл `ozon-seller-api` |
| `TG_BOT_TOKEN` | токен бота. Владелец токена — **только** tg-bridge (один polling на токен!) |
| `TG_TEAM_CHAT` | id командного чата, с префиксом `-100` |
| `WB_API_TOKEN` | Wildberries Seller API, если торгуете и там |
| `USER_*` | реквизиты ИП для налоговых документов: ФИО, ИНН, ОГРНИП, ОКТМО, код ФНС, налоговый режим/ставка/код льготы, регион, товарные знаки |
| `USER_OZON_BANK_ACCOUNT_*`, `USER_OZON_BANK_NAME` | расчётные счета (выписки, сверка КУДиР) |
| `OZON_AGENCY_CONTRACT_NUMBER`, `OZON_AGENCY_CONTRACT_DATE` | номер и дата агентского договора с Ozon — попадают в КУДиР |
| `OZON_SCOUT_PROXY` | **только на сервере**, если исходящий трафик идёт через прокси: `http://127.0.0.1:<port>`. Без него скрейпер конкурентов (`ozon_scout.py`) таймаутит — прозрачный iptables-редирект не ловит libcurl. На домашней машине с прямым резидентным IP **не задавать** |
| `MPSTATS_COOKIE` | сессионная кука mpstats.io для `tools/mpstats.py` (опционально) |
| `DIRECTBANK_*` | доступ к банковской выписке по стандарту 1С:DirectBank (опционально) |

## Правила

1. **Секреты не цитируются** — ни в TG, ни в журнале, ни в коммитах. Агент читает `.env`
   сам; в переписку значения не попадают.
2. `.env` в `.gitignore` вместе с `.env.*` (кроме `.env.example`). Проверяйте перед
   первым пушем: `git check-ignore -v .env`.
3. Ключи Ozon отзываются в ЛК одним кликом — если сомневаетесь, утёк ли, отзовите.
