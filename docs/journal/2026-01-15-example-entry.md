# 2026-01-15 — Выход из акции с отрицательной маржой (пример записи)

> Синтетический пример: показывает формат, цифры выдуманы.

## Что было
Дневной аудит акций показал: SKU `<sku>` участвует в акции с ценой 41 900 при базе
45 400. Netback по `pricing_engine` — 21 100 при себестоимости 22 400, то есть
−1 300 на юнит. Акция автопродлевается, за сутки ушло бы 2–3 штуки.

## Что решили
Выход из акции — T2 (guardrail `promos.auto_exit_if_margin_below_pct: 0` сработал),
апрув не нужен. Цену после выхода не трогали: база остаётся в коридоре.

## Что сделали
1. `ozon.py /v1/actions/products --dry` — проверили состав, SKU на месте.
2. `ozon.py /v1/actions/products/deactivate` — вышли.
3. Верификация обратным чтением: `/v1/actions/products` — SKU в акции больше нет.
4. В чат одной строкой: «Вышли из акции X по `<sku>`: маржа была −1 300 на юнит».

## Итог
Сэкономлено ≈ 3 900 ₽ за сутки при текущем темпе продаж. Акция больше не
автопродлевается.

## Что поменяли в системе
Ничего — плейбук отработал как написан. В `state/NOW.md` убран пункт «проверить акцию X».
