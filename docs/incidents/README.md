# incidents/ — постмортемы

Каждый факап → `YYYY-MM-DD-<slug>.md` по структуре:

1. **Симптом** — что увидели и когда. Как выглядело снаружи.
2. **Хронология** — что происходило по часам, включая ложные гипотезы.
3. **Root cause** — не «сервис упал», а почему он упал и почему этого никто не заметил.
4. **Как чинили** — конкретные команды и правки.
5. **Что поменяли, чтобы не повторилось** — guardrail, мониторинг, правило в CLAUDE.md.
   Постмортем без этого пункта не закрыт.
6. **Уроки** — что теперь знаем про то, как ломается именно наш магазин.

Агент читает эту папку при похожих симптомах — поэтому симптом формулируйте так, как
он выглядит в момент аварии, а не так, как выглядит после разбора.

Типичные кандидаты: просроченная отгрузка, требование ФНС, блокировка карточки,
демпинг-война, молча протухший OAuth-токен, расхождение ставки в прайс-API и в
фактических транзакциях.
