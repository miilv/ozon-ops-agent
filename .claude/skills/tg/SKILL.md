# tg — Telegram-мост

- Написать в командный чат: `python3 tools/tg.py send "текст"`
- В личку: `python3 tools/tg.py send "текст" --dm 100000001`
- Вопрос с кнопками (блокирует до ответа/таймаута; таймаут = отказ):
  `python3 tools/tg.py ask "Выхожу из акции X, маржа −2%. Ок?" --options да,нет --timeout 14400`
- История чата (bridge пишет всё, вкл. фото/голосовые как пути к файлам):
  `python3 tools/tg.py history 100`
Правила: в чате — результатами, не процессом; T3 — только через ask.
