# XML декларация УСН — формат и заполнение

Форма по приказу ФНС от 02.10.2024 № ЕД-7-3/813@ (актуальная на 2025-2026).

## Файл

- **Кодировка**: Windows-1251 (кириллица в названии полей и значениях)
- **Имя файла**: `NO_USN_<КодНО>_<КодНО>_<ИНН>_<DDMMYYYY>_<UUID>.xml`
  - `КодНО` — код вашей налоговой (в примере `0000`)
  - UUID — заглавные буквы, формат стандартного UUIDv4
- **Версия формата**: ВерсФорм="5.08", ВерсПрог="Налогоплательщик ЮЛ 4.90"
- **КНД**: 1152017

## Структура для УСН Доходы 1% (льготный регион)

```xml
<?xml version="1.0" encoding="windows-1251"?>
<Файл ИдФайл="..." ВерсПрог="..." ВерсФорм="5.08">
  <Документ КНД="1152017" ДатаДок="01.05.2026" Период="34" ОтчетГод="2025"
            КодНО="0000" НомКорр="0" ПоМесту="120">
    <СвНП>
      <НПФЛ ИННФЛ="770000000000">
        <ФИО Фамилия="Иванов" Имя="Иван" Отчество="Иванович"/>
      </НПФЛ>
    </СвНП>
    <Подписант ПрПодп="1"/>
    <УСН ОбНал="1">  <!-- 1 = Доходы; 2 = Доходы−Расходы -->
      <!-- СумНалПУ_НП = РАЗДЕЛ 1.1. Атрибуты АвПУКв/АвПУУменПг/АвПУУмен9м/НалПУУменПер
           ОБЯЗАТЕЛЬНЫ — это строки 020/040/070/100. Пропуск = ФНС читает нули →
           требование о пояснениях (типовая причина требования от ФНС). -->
      <СумНалПУ_НП ОКТМО="00000000" АвПУКв="0" АвПУУменПг="0"
                   АвПУУмен9м="0" НалПУУменПер="0">
        <РасчНал1 ПризСтав="1" ПризНП="2">
          <Доход   СумЗаКв="..." СумЗаПг="..." СумЗа9м="..." СумЗаНалПер="..."/>
          <Ставка  СтавкаКв="1" СтавкаПг="1" Ставка9м="1" СтавкаНалПер="1"
                   КодЛьгот="3462010/000100010001"/>
          <Исчисл  СумЗаКв="..." СумЗаПг="..." СумЗа9м="..." СумЗаНалПер="..."/>
          <УменНал СумЗаКв="..." СумЗаПг="..." СумЗа9м="..." СумЗаНалПер="..."/>
        </РасчНал1>
      </СумНалПУ_НП>
    </УСН>
  </Документ>
</Файл>
```

Без переносов и индентации (всё в одну строку). Бэкслэши экранировать не надо.

## Атрибуты Документа

- `Период="34"` — годовая декларация (стандарт). Другие коды: 50 (последний период при реорганизации/закрытии), 95 (при переходе на иной режим), 96 (при прекращении деятельности).
- `ПоМесту="120"` — по месту жительства ИП.
- `КодНО="0000"` — код налоговой инспекции; для конкретного ИП стабилен год от года.
- `НомКорр="0"` — первичная декларация. `1`, `2`... — корректировочные.
- `ПрПодп="1"` — подписывает налогоплательщик лично.

## Заполнение СумНалПУ_НП

- `ОКТМО="00000000"` — код по месту регистрации ИП. Свой — из уведомления Росстата / ФНС.
- `НалПУУменПер="0"` — налог к уменьшению за прошлые периоды отсутствует.

## РасчНал1 — основной расчёт

### `<Доход>` — нарастающим итогом
- `СумЗаКв` — за Q1
- `СумЗаПг` — за полугодие (накопит.)
- `СумЗа9м` — за 9 месяцев (накопит.)
- `СумЗаНалПер` — за год (накопит.)

Источник: Ozon Bank → Налоги → УСН → доход за каждый период (или собрать из API по методике cash-basis, см. `methodology.md`).

### `<Ставка>` — нарастающим итогом
1 (в льготном регионе 1%). `КодЛьгот="3462010/000100010001"` — обязательно при пониженной ставке.
Формат: `3462010` (признак пониженной ставки по региональному закону) `/` затем
4+4+4 цифры = номер статьи (0001) + пункта (0001) + подпункта (0001) закона субъекта,
с ведущими нулями. НЕ `3462010/01.200010000` — этот формат ФНС считает ошибочным
(по опыту требования от ФНС).

### Раздел 1.1 — атрибуты `СумНалПУ_НП` (строки 020/040/070/100)
Считаются из раздела 2.1.1, каждая строка = прирост обязанности за период:
- `АвПУКв` (020) = max(0, Исчисл_Q1 − УменНал_Q1)
- `АвПУУменПг` (040) = max(0, Исчисл_Пг − УменНал_Пг) − стр.020
- `АвПУУмен9м` (070) = max(0, Исчисл_9м − УменНал_9м) − (стр.020+040)
- `НалПУУменПер` (100) = max(0, Исчисл_год − УменНал_год) − (стр.020+040+070)

Если строка отрицательна — это «к уменьшению» (строки 050/080/110). Генератор
`build_usn_xml.py` пишет их автоматически.

### `<Исчисл>` — нарастающим итогом
Доход × ставка / 100, округлено до рубля.

### `<УменНал>` — нарастающим итогом
**Не больше Исчисленного** в каждом периоде (можно уменьшать налог не более чем на 100% для ИП без работников).

Логика расчёта поквартально для УСН Доходы 1%:
- Взносы за период = фиксированные (53 658 ₽ за 2025) + 1% свыше 300К (cap 300 888 ₽)
- УменНал[период] = min(Исчисл[период], Σ взносов за период)

Пример (доход 3/6/9/12 млн нарастающим итогом, ставка 1%):
- Q1: Исчисл=30 000, взносы накопит.=30 000 → УменНал=**30 000** (cap по исчисленному)
- H1: Исчисл=60 000, взносы=55 000 → УменНал=**55 000**
- 9M: Исчисл=90 000, взносы=55 000 → УменНал=**55 000**
- Y: Исчисл=120 000, взносы=55 000 → УменНал=**55 000**

### Расчёт К оплате (по периодам, Ozon Bank)
```
К оплате[период] = max(0, Исчисл[период] − УменНал[период]) − Σ К оплате[предыдущие периоды]
```

Тот же пример:
- Q1: max(0, 30 000−30 000) − 0 = **0**
- Q2 (сверх Q1): max(0, 60 000−55 000) − 0 = **5 000**
- Q3 (сверх H1): max(0, 90 000−55 000) − 5 000 = **30 000**
- Q4 (сверх 9M): max(0, 120 000−55 000) − 35 000 = **30 000**

Σ = 65 000 ₽ — годовая обязанность.

## Подача

- Через ЛК ИП на nalog.gov.ru → раздел деклараций → загрузить XML → подписать УКЭП
- Через спецоператора (СБИС, 1С-Отчётность, Контур, Калуга-Астрал)
- На бумаге через приёмную ИФНС (исключение)

## Корректировка после подачи

Если нашёл ошибку — подаёшь **корректировочную декларацию** (`НомКорр="1"` и т.д.) с теми же реквизитами, но обновлёнными суммами. Если корректировка увеличивает налог — сначала плати разницу, чтобы избежать штрафа 20% по ст. 122 НК РФ.
